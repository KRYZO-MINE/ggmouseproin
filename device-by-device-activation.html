Device-to-Device Activation Guide

Activate GG Mouse Pro without a computer using another Android device!

How to Activate Using Another Device

  1. Install GG Mouse Pro on both devices
  2. Connect both devices to the same Wi-Fi network
  3. Open GG Mouse Pro on both devices
  4. On the device you want to activate, select "Device-to-Device Activation"
  5. Select the other device from the list
  6. Confirm on the second device
  7. Wait for activation to complete
