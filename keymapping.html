Build your first keyboard and mouse keymap

Learn how to connect Android input devices, align a keymap with your game HUD, and save a profile in GG Mouse Pro 3.

Download & set upGet support

Test Android input first

Connect your devices through a supported USB adapter or Bluetooth. Type in a text field and check pointer movement. If either fails, solve the connection issue before changing game mappings.

Create a profile

  1. Complete activation and select the intended game profile.
  2. Use a stable screen orientation and save your in-game HUD.
  3. Place each mapping over the matching on-screen control.
  4. Assign distinct keys, then save the profile.
  5. Test movement, buttons, and camera behavior individually where permitted.

Choose a game guide

Use the Free Fire setup guide or PUBG Mobile setup guide for suggested bindings. These are starting points to customize, not guaranteed compatible presets.

Keep the layout consistent

A HUD change, screen resolution change, or different orientation can shift the target buttons. Save separate profiles for different layouts. If input stops altogether, follow troubleshooting before remapping everything.
