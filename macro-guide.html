Set up and troubleshoot macros

Understand macro triggers, timing, and troubleshooting in GG Mouse Pro 3, with a cautious workflow for testing repetitive input.

Download & set upGet support

What is a macro?

A macro groups input actions under a trigger. Availability and editor labels can vary by app version or plan. Start with ordinary keybindings so you can distinguish a mapping problem from a macro problem.

Only use automation where the app or game permits it. A working macro does not mean it complies with game rules, and no guide can guarantee protection from account penalties.

Create a small test

  1. Save a copy of the working profile.
  2. Open the macro controls available in your version; the macro video tutorial provides a visual reference.
  3. Choose a trigger that is not already assigned to another action.
  4. Begin with one action and one execution, using a permitted test environment.
  5. Save and test. Add another action only after the first works reliably.

Timing and trigger behavior

Distinguish a single press from a held or repeated trigger. Begin with a single-run sequence; verify how to stop it before enabling repetition. If an action is skipped, increase the interval gradually and retest. Long sequences are harder to diagnose and may fail when the screen changes.

Troubleshoot or restore

If a sequence fires twice, inspect duplicate bindings and repeat options. If the wrong button is pressed, check the current HUD against the mapped coordinates. If nothing responds, test a normal binding and review activation.

Disable the macro and restore the saved profile if behavior is unpredictable. When contacting support, include the app version, device model, trigger type, and a short description of the expected action.
