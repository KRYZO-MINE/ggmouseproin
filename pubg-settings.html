PUBG Mobile keyboard and mouse setup

Plan PUBG Mobile keybindings, check device input, and diagnose mapping problems with a practical keyboard and mouse setup checklist.

Download & set upGet support

Check game rules and compatibility

This guide describes a mapping workflow, not verified support for every PUBG Mobile release. Check the publisher’s current rules before using third-party controls. Successful Android input does not establish permission to use it in a game.

Connect your devices

  1. Connect the keyboard and mouse and test them outside the game.
  2. Install the app, then follow the applicable activation guide.
  3. Preserve your existing HUD and create a separate profile for the layout you intend to test.
  4. Align mapped controls with that layout. Save before entering a permitted practice session.

Plan your PUBG keybindings

Start with WASD for movement, Space for jump, R for reload, and F for interaction. Assign distinct, comfortable keys to crouch, prone, inventory, and weapon selection. Add vehicle controls only after the basic layout works.

Check tap and hold behavior separately, especially for aiming and leaning. Avoid assigning one key to multiple actions unless you explicitly intend that behavior.

Camera and sensitivity

Calibrate the camera before adjusting scoped sensitivity. Use a fixed mouse DPI and repeat the same motion at each setting. Keep notes so you can restore your previous values. Follow the sensitivity guide; copied settings rarely match every phone.

Macros and activation problems

Automation may be restricted by the game. Keep normal bindings working before considering advanced features, and do not assume macros or recoil automation are permitted. The macro guide explains basic testing and how to avoid overlapping triggers.

If input disappears after restarting the device, inspect activation status first. See troubleshooting before rebuilding the profile.
