Troubleshoot input and activation

Diagnose Android keyboard, mouse, activation, and keymap issues in order before rebuilding your GG Mouse Pro profile.

Download & set upGet support

Keyboard or mouse is not detected

Test the device outside the game. For USB, reconnect the adapter and test one peripheral at a time. Check your phone’s USB host support and any device-specific OTG setting. For Bluetooth, confirm pairing and battery state. A failure outside the game points to the connection rather than the keymap.

Android input works but game input does not

Inspect the app’s activation status and requested permissions. Follow the appropriate wireless or wired activation guide. Confirm that you selected the correct game profile and saved it.

Keys press the wrong controls

Compare the current HUD with the saved keymap. Check orientation, button size, and screen scaling. Realign one mapping and test it before changing the entire profile. See keymapping basics.

Prepare a useful support request

Include your phone model, Android version, app version, connection type, activation method, and exact error message. State whether input works outside the game and what changed before the problem started. Do not include passwords or pairing codes. Send these details through the support page.
